# SQLite公开元数据索引

## 决策

首版使用SQLite：一个采集/构建Worker写私有state，API只读不可变公开查询快照。仓库、包身份、版本及观察事实共享保存；Agent/type是查询维度，离线导出可按范围生成独立SQLite。

数据库文件大小本身不构成改用PostgreSQL或按Agent分库的理由。先测量查询计划、索引、并发与重建开销；出现明确多写入者、多机共享写入或优化后仍不满足负载需求时，再评估其他数据库和搜索架构。

## 事实与策略

指标按来源、口径、统计窗口和采样时刻独立保存；不在规范包记录中固化质量分、商业权重或本站背书。推荐来源的声明与可重建排序结果分开。下载次数不称为人数，未知不填零，Star/下载增长分别排序。

按UTC批次采集，默认8小时，可显式配置4小时。热门/新发现组取并集、按实际资源去重，普通资源保留轮巡机会。预算不足或来源失败时披露partial/stale，不承诺未验证的全目录每日覆盖。

## 发布与恢复

校验构建新revision后原子切换current，失败保留上一份可用快照。公开bundle不含个人凭据和private state；独立查询机器仅需公开runtime。备份私有state使用SQLite backup API，不能只复制忽略WAL的主文件。
